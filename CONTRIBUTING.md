# Contributing

Small, focused improvements are welcome. Development follows personal use and available time; an issue or pull request does not come with a response-time promise.

Use Node 24.15+ in the 24 LTS line. Run `npm ci`, `npm run typecheck` and `npm test`. Reproduce bugs with synthetic fixtures and test changed behavior. Keep the shared local/cloud interface consistent and source access read-only.

Do not include account credentials, signed URLs, personal books, annotations or generated indexes in issues or commits. Describe availability and error codes instead. Model and live-account tests are explicit opt-ins; the ordinary suite needs neither a Readest account nor installed model files.
