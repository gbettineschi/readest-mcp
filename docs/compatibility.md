# Compatibility and verification

This file records evidence, not a general compatibility guarantee. Checked 27 October 2026.

- Node 24.22.1 on macOS arm64 is the current local test runtime. The system Node installation is unchanged.
- Readest 0.12.16 is installed on this Mac. Local fixtures follow its `library.json`, managed book directories and per-book configuration. Passive reads do not launch the app or modify its data.
- Cloud fixtures follow Readest snapshot `44c90152f6b04e74f71245bb3642d9a7e03042ed`: raw DB records from separate books/configs/notes pulls, book `synced_at` pagination and note/config update/deletion clocks. This is a published application interface, not a guaranteed versioned developer API.
- Authentication follows the official KOReader integration's separate email/password session. Social-only accounts may require setting a password in Readest. This MCP never does that on the user's behalf and never imports the reader's session automatically.
- Default cloud project configuration is the vendor-published anonymous project URL/key from that snapshot's `.env`. Its JWT role was checked as `anon`; it is public project configuration, not an account session or service-role credential. Account sessions stay in private local storage.
- The cloud factory resolves the session's account identity before choosing its cache partition. Changing the account requires reconnecting the MCP, preventing previous-account cache reuse.
- Download requests use the account-qualified key `{userId}/Readest/Books/{bookHash}/{bookHash}.{ext}` required by Readest's parser and hash/extension fallback. A live file probe exposed the previously incomplete key; strict synthetic EPUB/PDF regressions now reject it. Account authorization is not forwarded to storage downloads.

Sources: [sync documentation](https://www.readest.com/docs/sync), [sync server](https://github.com/readest/readest/blob/44c90152f6b04e74f71245bb3642d9a7e03042ed/apps/readest-app/src/pages/api/sync.ts), [download endpoint](https://github.com/readest/readest/blob/44c90152f6b04e74f71245bb3642d9a7e03042ed/apps/readest-app/src/pages/api/storage/download.ts), [KOReader authentication](https://github.com/readest/readest/blob/44c90152f6b04e74f71245bb3642d9a7e03042ed/apps/readest.koplugin/readest_supabaseauth.lua).
## Fixture and installation checks

- 99 default tests passed on macOS arm64: all six real MCP tools in local and loopback-cloud processes, identical definitions, exact-reference retrieval, long chapter continuation, stale editions, missing versus empty notes, cloud timeouts with/without cache, content limits and private path/session boundaries. Nine additional regressions from the whole-branch review/author pass were observed failing before their fixes: mixed PDF gaps, vector coverage beyond 50 books and by target, context-edition continuation, offloaded text freshness, empty cached cloud results, long notebook summaries, operation-specific warnings content continuation beyond one million characters, and account changes within the metadata reuse window.
- A packed production-only install in a clean directory passed initialization, tool discovery, EPUB extraction/search and an exact-reference round trip with optional dependencies omitted. A separate installed package with optional dependencies passed real local-model inference.
- Production dependency audit reported no known vulnerabilities at the check time. Dependency licenses were inspected; the model is downloaded separately.
- Readest 0.12.16 was rechecked on this Mac. No saved library was found in the bounded standard local paths. No live local library or Drive sync was tested.
- Separate cloud sign-in, authenticated catalogue reads and forced session renewal succeeded. A subsequent owner-authorized import exercised 25 EPUBs and one PDF: all 26 cloud downloads matched the selected source fingerprints, all 26 were indexed, and each passed a structure-to-passage reference round trip through the real SDK/client. The final PDF check identified 55 native-text pages, two image-only covers recovered with local OCR, and seven zero-operator blank pages. Extracted-text coverage is complete; OCR accuracy remains explicitly qualified. Annotation lists were empty on these newly imported books, so saved-highlight retrieval remains unverified on real annotations. Personal books/text are not included in this repository. The private session file remained 0600; no browser/app token was extracted and no password was stored.
- A fresh local Codex app-server client discovered all six tools and successfully called library_status against the authorized cloud account, using an ephemeral diagnostic session rather than a saved chat. Prior client settings were preserved. Current-chat reconnection has not been demonstrated; the running app's optional control socket was unavailable, so an existing chat may need reopening.
- [GitHub CI passed](https://github.com/gbettineschi/readest-mcp/actions/runs/40572119193) on Node 24/macOS, Linux and Windows for code commit 832c714, including typecheck, all 99 default fixture/package tests, build and package checks. Real-model and live-account tests remain opt-in and were run separately on this Mac. Windows PDF resource paths and npm spawning were corrected from actual runner failures before this passing run.

## Semantic retrieval and corpus acceptance

The initial E5-small check passed six same-language paraphrases in a tiny synthetic corpus but did not establish cross-language library quality. A real 26-book probe exposed Italian-to-English ranking failures and short-heading/index dominance. Recomputed vectors matched persisted values in a sampled check. Filtering short text, E5-small fp32 and E5-base q8 did not repair the observed focus query. A model-only MiniLM change improved some queries but failed the full-corpus acceptance check and was rejected as a sufficient fix.

The current pinned q8 multilingual MiniLM model uses plain text, mean pooling and normalized 384-dimensional vectors, with its 128-token budget enforced. Consecutive EPUB paragraphs within the same source section/resource/spine and continuous normalized offsets form derived semantic documents. Raw paragraphs remain unchanged for keyword search and reading. PDF pages and annotation targets remain separate. Matching semantic windows have bounded, source/text-bound references; hybrid combines document ranks while preserving an available exact lexical window. No length-based rank penalties, book-specific class filters or remote translation are used.

On this Mac, 102 tests passed with the actual optional local model and Tesseract enabled; the live-account test remained separately opt-in. The semantic checks include original English/Italian examples with same-language and short-heading distractors. They are regression checks, not a general model benchmark.

The final private index contains all 26 books and 27,830 current embedding windows. Six paired Italian/English queries covering concentration, deliberate skill practice and communicating needs each returned substantive expected source material within the top five, with exact-reference retrieval through the installed MCP. The same test checked OCR references for two image-only PDF pages and empty content for a blank page, without missing-text warnings. A separate full installed-server exercise passed all six tools, catalogue pagination and source-to-passage round trips for all 26 books. Retrieved passages are not all equally relevant; this limited acceptance set does not establish exhaustive conceptual recall. The private texts and reports remain outside the repository.

A synthetic persistence probe with a 999,999-character semantic document and 2,500 vectors took 6,199 ms before parent reuse and 7 ms after it, excluding inference. This single-host comparison verifies the repeated-deserialization fix, not production throughput. Vector replacement still validates the complete batch atomically, including rejecting non-persisted range aliases. Review regressions also cover OCR render timeouts, obsolete extraction profiles, expired structure references, Unicode/source boundaries, keyword preservation and distant lexical/semantic windows.
